조회 범위와 한계

OpenSky는 전 세계 수신망 관측 결과를 조회합니다. 장애나 제한 시 ADSB.lol, adsb.fi의 인천 중심 250해리로 전환합니다. 정상 빈 응답은 전환 사유가 아닙니다. 최소 조회 간격은 30초이고, 제공자의 대기 헤더를 존중합니다. 실패하면 이전 응답을 유지합니다. 페이지 실행·복귀 시 자동 조회하며 반복 네트워크 타이머·백그라운드 조회는 없습니다.

개인정보 처리방침

웹 버전은 광고·분석·추적 SDK를 사용하지 않고 사용자 현재 위치를 요청하지 않습니다. 페이지 실행·복귀 시 공개 위치 API를 자동 조회합니다. 항공편 선택 시 호출부호를 ADSBDB에 전송하여 편명과 등록 경로를 조회합니다. 실제 운항과 다를 수 있습니다. 검색어는 메모리에서 처리합니다. 최근 항공기 위치와 저장 시각은 이 브라우저에 보관하며 설정의 저장 항적 삭제로 제거할 수 있습니다. 지도 배경은 오프라인에서 표시되지 않을 수 있습니다. 웹 조회는 이 사이트 서버를 통해 제공자에게 전달됩니다. 서버 프로세스 메모리에 응답과 제공자 제한 상태를 일시적으로 보관하여 중복 요청을 줄입니다.

이 공개 사이트의 호스팅은 ChatGPT Sites가 제공합니다. 호스팅 서비스는 접속 IP와 요청 정보를 처리할 수 있습니다. 이 앱은 전달받은 계정 식별 정보를 저장하거나 이용하지 않습니다.

지도 타일은 OpenStreetMap에서 가져옵니다. 지도 서비스에 접속 IP와 지도 타일 요청이 전달됩니다. API 제공자는 서버 IP 및 요청 정보를 받습니다. 제공자와 호스팅 서비스의 로그 보관은 각 정책을 따릅니다. 앱 자체에는 사용자 개인정보를 저장하는 데이터베이스가 없습니다.
